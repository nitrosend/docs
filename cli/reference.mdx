# Command reference

This page is generated from the command descriptors of `@nitrosend/cli` 0.3.10. `nitrosend <command> --help` prints the same usage and examples, and `nitrosend describe <command> --json` returns the full descriptor: every flag with its type and allowed values, which are required, the safety class and the idempotency policy.

<Tip>
  In agent runners, prefer `nitrosend describe` over this page. The descriptor returned by the CLI always matches the binary you're running.
</Tip>

## MCP

The CLI is the Nitrosend MCP, callable from a shell. These commands dispatch JSON-RPC over HTTP to the same endpoint chat MCP clients use.

| Command | Summary |
|---|---|
| `nitrosend mcp initialize [--json]` | Initialize MCP handshake. |
| `nitrosend mcp tools list [--json]` | List MCP tools. |
| `nitrosend mcp tools call <name> [--args '{...}']` | Call an MCP tool. |
| `nitrosend mcp resources list [--json]` | List MCP resources. |
| `nitrosend mcp resources read <uri>` | Read an MCP resource. |
| `nitrosend mcp prompts list [--json]` | List MCP prompts. |
| `nitrosend mcp prompts get <name> [--args '{...}']` | Get an MCP prompt. |

The full set of available tools (`nitro_get_status`, `nitro_compose_campaign`, …) is documented under the [MCP Tools](/mcp) tab.

## Global options

Every command takes these.

| Option | Effect |
|---|---|
| `--help` | Print usage; after a command, that command's usage and examples. |
| `--version` | Print the CLI version. |
| `--json` | Print the JSON result envelope. |
| `--ndjson` | Print newline-delimited JSON. |
| `--csv` | Print rows as CSV. |
| `--machine` | Agent mode: implies --json --non-interactive --no-color --no-pager. |
| `--non-interactive` | Never prompt; fail closed when input would be needed. |
| `--no-color` | Strip ANSI colour. |
| `--no-pager` | Never page output. |
| `--dry-run` | Validate without side effects, where the command supports it. |
| `--yes` | Skip ordinary confirmations; never a typed confirmation. |
| `--explain` | Return the resolved plan as data and run nothing. |
| `--trace` | Write timing diagnostics to stderr. |
| `--profile <name>` | Use this stored profile. |
| `--api-url <url>` | Use this MCP endpoint. |

Older spellings still work: `--limit` for `--per`, `--list` for `--list-id`, `--json-args` for `--args`.

See [Agent mode](/cli/agent-mode) for the full envelope shape and exit code map.
