# Claude Cowork + Nitrosend MCP

[Claude Cowork](https://claude.ai/cowork) is Anthropic's collaborative AI workspace. Connect Nitrosend via MCP and your team can manage email marketing through conversation — create campaigns, build flows, check analytics, and more, all within Cowork.

## What is MCP?

**MCP (Model Context Protocol)** is an open standard that lets Claude connect directly to external services. When Nitrosend is connected, Claude gets native access to the full public set of email marketing tools plus live resources about your brand, account, and email best practices.

## Setup: Enable the Nitrosend connector

Cowork runs inside the Claude Desktop app and shares its connectors, so enabling Nitrosend once covers both.

<Steps>
  <Step title="Open Connectors">
    In the Claude Desktop app, go to **Settings** → **Connectors**.
  </Step>
  <Step title="Find Nitrosend and connect">
    Search for **Nitrosend** and click **Connect**. The same listing is at [claude.ai/directory/nitrosend](https://claude.ai/directory/nitrosend); connecting there makes Nitrosend available in Cowork too.
  </Step>
  <Step title="Sign in">
    Claude will open a Nitrosend sign-in window. Log in or create a free account — no API key needed.
  </Step>
  <Step title="Start using Nitrosend">
    Nitrosend is now available as a connector in your Cowork workspace. Open a new conversation and start prompting:

    ```
    What's my Nitrosend account status?
    ```
  </Step>
</Steps>

## Why Cowork for email marketing?

Cowork's collaborative workspace is particularly powerful for email marketing because:

- **Team context** — share conversations about campaigns, flows, and strategy with your team
- **Persistent projects** — keep email marketing as an ongoing project where Claude remembers your goals, brand, and past campaigns
- **Multi-step workflows** — complex tasks like "plan our Q2 email strategy, then build the flows" work naturally in Cowork's project format

## Example workflows in Cowork

### Plan and execute a campaign

```
Let's plan our March newsletter. Check my recent campaign performance, 
then create a new campaign targeting subscribers who opened the last 
email. Include a section about our new features.
```

### Audit your email setup

```
Review my Nitrosend account setup. Check my Brand Kit, sending 
domain health, and active flows. Are there any improvements you'd 
recommend?
```

### Build a complete flow

```
I need a complete abandoned cart recovery flow. Build a 3-email 
sequence: first email 1 hour after cart abandonment, second after 
24 hours, third after 3 days with a discount offer.
```

## Supercharge with Brand Kit & Memory

For the best results in Cowork, make sure you've configured:

1. **Brand Kit** ([app.nitrosend.com/my/brand](https://app.nitrosend.com/my/brand)) — your brand colors, fonts, logo, and company description
2. **AI Memory** ([app.nitrosend.com/my/settings/memory](https://app.nitrosend.com/my/settings/memory)) — your marketing goals, target audience, and email strategy

Claude reads these automatically through MCP, so every email it creates matches your brand and follows your strategy.

## All MCP tools available in Cowork

The full public set of Nitrosend MCP tools is available in Cowork — the same tools available in Claude Desktop and Claude Code. See the [Claude Code](/integrations/claude-code#mcp-tools-available) page for the complete tool reference.

<Info>
  The connector requires no local software installation. Everything runs server-side through Nitrosend's MCP endpoint at `api.nitrosend.com/mcp`. If your Claude organisation restricts directory connectors, an organisation owner can enable Nitrosend or add it as a custom connector with that URL; see the [Claude Desktop guide](/integrations/claude-desktop#fallback-custom-connector).
</Info>
