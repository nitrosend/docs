# AWS Marketplace

Nitrosend's AWS Marketplace integration uses the existing Nitrosend dashboard. AWS owns the paid plan and eligible usage charges; Nitrosend owns your brands, campaigns, contacts, templates, sending setup and usage controls.

Nitrosend is available on [AWS Marketplace](https://aws.amazon.com/marketplace/pp/prodview-ln4b3e3r2ka6q). Choose Free at $0/month, Pro or Ultra there, then choose **Set up your account**. The listing shows the current contract prices, included allowances and eligible overage rates.

## Link a subscription

After you subscribe in AWS Marketplace, AWS opens Nitrosend with a one-time registration token. Nitrosend verifies that token directly with AWS and then asks you to sign in or create an account.

Choose the Nitrosend account that should use the AWS license and approve the link. An AWS request never silently attaches itself to an existing Nitrosend account. After approval, Nitrosend reads the license entitlement from AWS and shows the plan on the existing Billing page.

Each AWS license stays separate. If one AWS account buys more than one agreement, ending one license does not end another license.

## Plans and usage

The offer includes Free at $0/month, Pro at $20/month and Ultra at $100/month. Free uses the same Nitrosend Free plan: 8,000 emails to start, then 500/month, 20 AI actions/month, 3 brands, 1 custom sending domain, 1 seat and unlimited stored contacts. API, CLI and MCP access are included.

Free has no charged overages, no card collection by Nitrosend and no automatic conversion to a paid plan. Work stops at the Free allowance limits. Initial allowances belong to the Nitrosend account; linking or renewing an AWS license does not reset them. Upgrade by choosing a paid plan in AWS Marketplace and explicitly accepting its charges.

Pro and Ultra include their normal monthly email, SMS and AI allowances. Eligible use above those paid allowances is reported to the same AWS license each hour and appears through AWS Marketplace billing.

Paid AWS plans support:

- email overage
- US and Canada SMS overage
- Australia SMS overage
- AI action overage

Nitrosend applies the normal allowance, spend cap, trust and delivery checks before work runs. A resource that is not priced in the AWS offer is unavailable through that license; it is not moved to a saved card.

## Manage billing

Use the Nitrosend Billing page to review:

- the linked plan and current allowance period
- email, SMS and AI use
- included and excess usage
- spend-cap or entitlement holds
- the AWS ownership state

Use AWS Marketplace to change or end the subscription. Nitrosend does not ask for a card for an AWS-owned plan. If AWS changes or ends the entitlement, Nitrosend verifies the current license state before changing access.

## Support

Use [Nitrosend support](https://app.nitrosend.com/support) for account, sending and usage questions. Use AWS Marketplace for agreement, invoice and payment administration.
