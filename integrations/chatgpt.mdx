# ChatGPT

Nitrosend is an official plugin in ChatGPT's plugin directory, listed as **Nitrosend - AI Email Marketing**. Connect it once and ChatGPT can compose, test and send your email marketing. ChatGPT handles the MCP connection and Nitrosend signs in your account: no API key, no config files.

## Connect Nitrosend

**[Add Nitrosend to ChatGPT →](https://chatgpt.com/apps/nitrosend---ai-native-email/asdk_app_69c236abbea481918d9180a100abd6b0)**

<Steps>
  <Step title="Open the Nitrosend listing">
    Click **Add Nitrosend to ChatGPT** above. It opens Nitrosend in ChatGPT's plugin directory. If it doesn't open the listing, search for **Nitrosend** in the plugin directory instead.
  </Step>
  <Step title="Connect and sign in">
    Click **Connect**. ChatGPT opens the Nitrosend sign-in: log in or create a free account. Before connecting, you can [choose access to one account or brand](/integrations/overview#choose-connection-access); the choice applies to every chat using that connection.
  </Step>
  <Step title="Use it anywhere you use ChatGPT">
    The connection belongs to your ChatGPT account, so Nitrosend is then in ChatGPT on the web, the desktop app and the mobile apps. If the tools don't appear right after connecting, start a new chat.
  </Step>
</Steps>

<Tip>
  Using the ChatGPT desktop app? Nitrosend's own agent setup screen has **Open in the ChatGPT app**: it opens a new chat with Nitrosend selected and your first job typed, and ChatGPT asks you to connect Nitrosend the first time. Nothing is sent until you press send.
</Tip>

## Use Nitrosend in a conversation

Ask ChatGPT anything about your email marketing:

```
What's my Nitrosend account status?
```

```
Create a welcome email flow for new subscribers
```

## Add your own images and animated GIFs

Attach an image or animated GIF to your ChatGPT message, or paste a public link, and ask ChatGPT to use it in your email. ChatGPT saves it to Nitrosend and places it in the design. GIFs keep their animation, so you can lead with a moving hero. Video files aren't accepted, because most email apps don't play video: turn the clip into a GIF first. See [Images and GIFs](/guides/images-and-gifs).

```
Use the attached GIF as the hero of my newsletter draft in Nitrosend and send me a test
```

## Building your own app instead

Calling Nitrosend from your own code rather than from ChatGPT? Use the [REST API](/integrations/rest-api) with an API key, or the [Vercel AI SDK tools](/integrations/vercel-ai-sdk). The [API reference](/api/) is generated from the OpenAPI spec at `https://api.nitrosend.com/openapi.yaml`.
