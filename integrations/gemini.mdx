# Google Gemini + Nitrosend MCP

Gemini CLI has native MCP support, giving you the full Nitrosend toolkit — every public tool, live Brand Kit context, and account state — directly in your terminal.

## Setup

### Step 1: Add the MCP server

Run this in your terminal:

```bash
gemini mcp add --scope user --transport http nitrosend https://api.nitrosend.com/mcp
```

`--scope user` makes Nitrosend available in every project. Prefer to edit the config yourself? Add this to `~/.gemini/settings.json` instead:

```json
{
  "mcpServers": {
    "nitrosend": {
      "httpUrl": "https://api.nitrosend.com/mcp"
    }
  }
}
```

Using Google Antigravity? It needs `serverUrl` instead of `httpUrl`. See the [Antigravity guide](/integrations/antigravity).

### Step 2: Sign in

Start Gemini CLI and run `/mcp auth nitrosend`. Your browser opens the Nitrosend sign-in: log in or create a free account. No API key needed.

### Step 3: Use it

```bash
gemini "Check my Nitrosend account status and draft a welcome email"
```

```bash
gemini "Create a campaign for our product launch and target my VIP segment"
```

Gemini now has every public Nitrosend MCP tool: composing emails, managing contacts, building flows, checking analytics and more.

<Tip>
  MCP gives Gemini your full Brand Kit context — colors, fonts, tone of voice — so emails it creates are on-brand without extra prompting.
</Tip>

## Example workflows

### Set up Brand Kit + compose

```bash
gemini "Scrape my Brand Kit from https://mysite.com and draft a product announcement email"
```

### Build a flow

```bash
gemini "Create a welcome flow that sends 3 emails over a week when someone subscribes"
```

### Check performance

```bash
gemini "Show me insights for my last campaign compared to benchmarks"
```

## Building your own app instead

Calling Nitrosend from your own code with the Google AI SDK rather than from Gemini CLI? Use the [REST API](/integrations/rest-api) with an API key. The [API reference](/api/) is generated from the OpenAPI spec.
