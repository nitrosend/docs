# Stripe Projects

Nitrosend is a provider on [Stripe Projects](https://projects.dev). One
command creates or links a Nitrosend account, provisions a sending brand with
an API key and a hosted sender, writes the credentials to your `.env`, and
lets you pick, upgrade and downgrade tiers from the terminal. Everything the
CLI creates is an ordinary Nitrosend account you can open in the dashboard.

Availability depends on Stripe listing Nitrosend in the Projects catalog.
Until then, use the regular dashboard and API key flow.

## Quickstart

```bash
stripe plugin install projects
stripe projects init
stripe projects add nitrosend/email --config '{"company_name":"Acme Coffee","website":"https://acme.example"}'
stripe projects env --pull
```

`add` returns `NITROSEND_API_KEY`, `NITROSEND_API_URL`, `NITROSEND_MCP_URL`,
`NITROSEND_BRAND_SID` and `NITROSEND_FROM_ADDRESS`. The sender is
`hello@<company>.nitrosend.net`, reserved for you and activated on your first
send; no DNS is needed. If you omit `company_name`, the CLI asks for it before
the sender can be reserved.

`stripe projects llm-context` points your coding agent at the Nitrosend agent
guide: the variables, the MCP connection and the first send.

## Accounts

Linking needs no browser. Stripe verifies the email on your Stripe account,
and the link is made in one step:

- **New to Nitrosend.** That email gets a Nitrosend account, owned by you,
  with the normal dashboard access.
- **Already a Nitrosend user.** The account you administer is linked. If you
  administer several, the CLI asks which one.
- **Already paying Nitrosend directly.** Your plan and card stay as they are;
  change the plan in the dashboard.

A Stripe account links to one Nitrosend account, so teammates working on the
same Stripe account work on the same Nitrosend account.

`stripe projects unlink nitrosend` removes the link and keeps the account.

## Tiers and billing

Tiers are the public Nitrosend plans: Free, Pro and Ultra. Every tier has
unlimited contacts; agent and API calls are not metered. Enrichment and
email validation are metered per use on every tier.

```bash
stripe projects upgrade nitrosend      # pick pro or ultra
stripe projects downgrade nitrosend    # back to free
```

A paid tier is charged to the card on your Stripe Projects billing profile
through a Shared Payment Token. Nitrosend runs the subscription in its own
Stripe account with that token as the payment method, so the first charge and
every renewal stay inside your Stripe Projects spending limit and show in
`stripe projects spend`. An upgrade is charged the difference at once. Ultra
costs more than the default Stripe Projects spending limit, so raise your
limit in your Stripe account settings before choosing it. The dashboard shows
the plan and routes plan changes back to the CLI.

## Credentials

`stripe projects rotate nitrosend/email` issues a new API key; the previous
key keeps working for 24 hours. `stripe projects remove nitrosend/email`
deprovisions the resource: the key is revoked after a grace period, the
brand and its content stay, and the account stays.

## Sending from your own domain

The hosted sender needs no DNS. To send from your own domain, open
Settings > Domains in the dashboard, add the domain, publish the records it
prints, and select it. Both senders can coexist.

## Stripe customer data

Nitrosend can also import the customers, subscriptions and invoices from the
Stripe account you build on and turn them into segments, merge fields and
flow triggers. See [Stripe](/integrations/stripe).

## Dashboard

`stripe projects open nitrosend` prints a one-time sign-in link to the
dashboard for this account. The link expires after five minutes and works
once.
