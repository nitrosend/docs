# OpenAI Codex CLI

[Codex CLI](https://github.com/openai/codex) is OpenAI's terminal-based coding agent. Connect it to Nitrosend over remote MCP for every public Nitrosend tool.

<Info>
  This guide is for the Codex CLI. Using Codex in the ChatGPT desktop app? Nitrosend is in ChatGPT's plugin directory; see the [ChatGPT guide](/integrations/chatgpt).
</Info>

## Setup

Codex CLI supports Nitrosend as a remote HTTP MCP server.

### 1. Add the MCP server

```bash
codex mcp add nitrosend --url https://api.nitrosend.com/mcp
```

### 2. Sign in with OAuth

```bash
codex mcp login nitrosend
```

Codex opens the Nitrosend sign-in flow in your browser. Log in or create a free account.

### 3. Use Nitrosend from Codex

```bash
codex "Check my Nitrosend account status"
codex "Create a welcome email flow for new subscribers"
codex "Send our newsletter to the active subscribers list"
```

<Info>
  No API key is required for the standard Codex MCP setup.
</Info>

## Automation without OAuth

For scripts and CI, use an API key instead of the sign-in: Codex CLI supports `--bearer-token-env-var` with a Nitrosend API key, or call the [REST API](/integrations/rest-api) directly. Create keys under **Settings > API Keys** in the Nitrosend dashboard ([app.nitrosend.com/my/settings/api-keys](https://app.nitrosend.com/my/settings/api-keys)).
