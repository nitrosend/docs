# Agent Onboarding

Nitrosend is built MCP-first, so an AI agent can run the whole email stack — campaigns, flows, contacts, transactional sends, deliverability — as native tools. This page is the human-readable overview. The full, machine-readable onboarding skill lives in a single file your agent can fetch and follow:

## MCP path

One command (or a custom connector) plus OAuth sign-in:

```bash
claude mcp add --transport http nitrosend https://api.nitrosend.com/mcp
```

Call `nitro_get_status` first for account context, then read the `nitro://guide` resource. Full per-client setup is in the [Quickstart](/quickstart) and [MCP integrations](/integrations/overview).

## Headless path (no dashboard, no MCP client)

<Steps>
  <Step title="Create an account">
    `POST /v1/signup` with `{ "user": { "email", "password" } }`. Returns a 15-day JWT in the `Authorization` response header.
  </Step>
  <Step title="Mint an API key">
    `POST /v1/my/api_keys` with that JWT returns `nskey_live_...`. Store it as a secret.
  </Step>
  <Step title="Prepare the reserved sender">
    Get the brand SID from `GET /v1/my/brands`, then call `POST /v1/my/brands/{sid}/prepare_sending`. Account creation reserves only the protected `<brand>.nitrosend.com` name; this explicit call creates its DNS, DKIM, provider identity, and tenant resources asynchronously. Poll the brand until `brand_subdomain.ready` is `true`, then select a From local part with `PATCH /v1/my/brands/{sid}` and `{ "sender_local_part": "hello" }`.
  </Step>
  <Step title="Send once ready">
    `POST /v1/my/messages` with `{ "channel": "email", "to", "subject", "html" }` and an `Idempotency-Key` header. If an eligible first send starts preparation instead, the API returns a retryable `sender_identity_provisioning` response and stores no message; retry the same request only after readiness and explicit sender selection.
  </Step>
  <Step title="Choose optional production upgrades">
    A customer-owned sending subdomain builds portable reputation and never consumes the reserved Nitrosend brand-subdomain sender. Paid plans and checkout remain optional; `$0` plans need no card.
  </Step>
</Steps>

<Info>
  Node and Python `fetch` / `requests` calls work as-is. Only the bare `Python-urllib` user agent is blocked by the WAF.
</Info>
