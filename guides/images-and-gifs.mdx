# Images and GIFs

Nitrosend accepts PNG, JPEG, GIF and WebP images in emails. Upload one from an
Image section in the email editor, and Nitrosend will host it for you. You can
also use **Use direct URL** if the image is already hosted at a public link.

Uploads must be under 10 MB, no more than 4,000 pixels on either side, and no
more than 16 million pixels in total. SVG files are not supported.

## Animated GIFs

To add an animated GIF, select an Image section and upload the GIF as you would
any other image. Nitrosend keeps its animation when it hosts the file. You can
also paste a public GIF link using **Use direct URL**.

If you build the email with an agent, give it a public link to the GIF. It can
save the image to Nitrosend and use it in the email.

Send yourself a test before sending to your audience. Email apps handle
animation differently, and some show only the first frame. Put the key message
in that first frame and add alt text for readers whose images are hidden.

Keep GIFs small so they load promptly on mobile connections. A width of about
1,200 pixels is enough for a full-width image in a 600-pixel email.
