# Dashboard URLs

The Nitrosend dashboard lives at `https://app.nitrosend.com` and every signed-in page sits under the `/my/` prefix, for example `https://app.nitrosend.com/my/settings/api-keys`. A path without `/my/` (such as `/settings/api-keys`) does not exist and shows a "Page not found" screen. URLs are not account- or brand-scoped: the brand switcher in the sidebar footer decides which brand a page shows.

<Info>
  **For AI agents:** cite dashboard links only from this page. If a page is not listed here, say the link is not documented rather than guessing a path. Pages marked *gated* only appear for accounts with that feature enabled.
</Info>

## Pages for a single record

Replace `{id}` with the record's ID.

| Page | URL pattern |
| --- | --- |
| Campaign | `https://app.nitrosend.com/my/campaigns/{id}` |
| Flow | `https://app.nitrosend.com/my/flows/{id}` |
| Template editor | `https://app.nitrosend.com/my/templates/{id}` |
| Template preview | `https://app.nitrosend.com/my/templates/{id}/preview` |
| Contact | `https://app.nitrosend.com/my/contacts/{id}` |
| Edit contact | `https://app.nitrosend.com/my/contacts/{id}/edit` |
| Contact list | `https://app.nitrosend.com/my/contact-lists/{id}` |
| Edit contact list | `https://app.nitrosend.com/my/contact-lists/{id}/edit` |
| Integration | `https://app.nitrosend.com/my/integrations/{id}` |
| Inbox thread | `https://app.nitrosend.com/my/inbox/{id}` |
| Outreach campaign | `https://app.nitrosend.com/my/outreach/{id}` |
| API key | `https://app.nitrosend.com/my/settings/api-keys/{id}` |

## Older links that still work

Settings used to live under Brand. These paths redirect to the pages above, so a link saved before the move is not broken: `/my/brand/api-keys`, `/my/brand/domains`, `/my/brand/memory`, `/my/brand/channels`, `/my/settings/account`, `/my/settings/team`, `/my/settings/billing`, `/billing` and `/campaigns/{id}`.
