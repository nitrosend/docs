# Dashboard URLs

The Nitrosend dashboard lives at `https://app.nitrosend.com`. Most dashboard links begin with `https://app.nitrosend.com/my/`, for example `https://app.nitrosend.com/my/settings/api-keys`; use the complete path shown below. Ordinary dashboard links open in your selected account and brand, which you change from the account menu at the top right of the dashboard. Some emailed links can open a specific account or brand you have access to.

<Info>
  **For AI agents:** cite dashboard links only from this page. If a page is not listed here, say the link is not documented rather than guessing a path. Pages marked *gated* only appear for accounts with that feature enabled.
</Info>

## Older links that still work

Settings used to live under Brand. These paths redirect to the pages above, so a link saved before the move is not broken: `/my/brand/api-keys`, `/my/brand/domains`, `/my/brand/memory`, `/my/brand/channels`, `/my/settings/account`, `/my/settings/team`, `/my/settings/billing`, `/billing` and `/campaigns/{id}`. `/my/sends` and `/my/sends/overview` now open **Activity** and **Activity > All email**.
