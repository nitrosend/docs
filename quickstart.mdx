# Quickstart

Get up and running with Nitrosend in under 5 minutes. Choose your path:

<Info>
  All plans, including free plans, have full access to Nitrosend MCP/API/CLI. Plan limits still apply to send volume, seats, AI action allowances, and paid add-ons. The Free plan includes 8,000 free emails up front, then 500 free emails every month.
</Info>

<Tip>
  **Are you an AI agent?** Read the [Agent Onboarding](/agent-onboarding) page for the full tool surface, send modes, and the headless signup-to-send path, or fetch the machine-readable skill at [nitrosend.com/skill.md](https://nitrosend.com/skill.md).
</Tip>

## Quickstart with AI (recommended)

The fastest way to get started. Connect your AI tool and let it handle the setup.

### 1. Create your account

Sign up at [app.nitrosend.com](https://app.nitrosend.com).

### 2. Connect your AI tool

Add Nitrosend as an MCP server, then sign in. Pick your tool:

<Tabs>
  <Tab title="Claude Code">
    Install the Nitrosend plugin, which brings the server and Nitrosend's email skills:

    ```bash
    claude plugin marketplace add nitrosend/claude
    claude plugin install nitrosend@nitrosend
    ```

    Then run `/mcp` inside Claude Code and complete the Nitrosend sign-in. Prefer the server on its own? `claude mcp add --transport http nitrosend https://api.nitrosend.com/mcp` instead. Full walkthrough in the [Claude Code guide](/integrations/claude-code).
  </Tab>
  <Tab title="Claude Desktop / Claude.ai">
    Enable the official **Nitrosend** connector, not the CLI. In Claude Desktop (or Cowork), go to **Settings** → **Connectors**, search for `Nitrosend` and click **Connect**. On Claude.ai, open [claude.ai/directory/nitrosend](https://claude.ai/directory/nitrosend) and click **Connect**.

    Sign in when prompted. No API key, no URL to paste.
  </Tab>
  <Tab title="ChatGPT">
    Add the official Nitrosend plugin from ChatGPT's plugin directory, click **Connect**, and sign in. No config, no API key. It then works in ChatGPT on the web, the desktop app and the mobile apps.

    [Add Nitrosend to ChatGPT →](https://chatgpt.com/apps/nitrosend---ai-native-email/asdk_app_69c236abbea481918d9180a100abd6b0)

    If the link doesn't open the listing, search for **Nitrosend** in ChatGPT's plugin directory. Full walkthrough in the [ChatGPT guide](/integrations/chatgpt).
  </Tab>
  <Tab title="Codex CLI">
    Add the server, then sign in:

    ```bash
    codex mcp add nitrosend --url https://api.nitrosend.com/mcp
    codex mcp login nitrosend
    ```

    Codex CLI connects directly to the remote MCP server. For ChatGPT, use the ChatGPT tab.
  </Tab>
  <Tab title="Cursor">
    Nitrosend is an official plugin on the Cursor Marketplace. In Cursor's Agent chat, run:

    ```
    /add-plugin nitrosend
    ```

    Or click **Add to Cursor** on the listing: [cursor.com/marketplace/nitrosend](https://cursor.com/marketplace/nitrosend). The first Nitrosend tool call opens the sign-in window. No API key, no config file.

    Prefer to manage MCP servers yourself? Add the same server to `~/.cursor/mcp.json` (all projects) or `.cursor/mcp.json` (this repo):

    ```json
    {
      "mcpServers": {
        "nitrosend": {
          "url": "https://api.nitrosend.com/mcp"
        }
      }
    }
    ```

    Full walkthrough in the [Cursor guide](/integrations/cursor).
  </Tab>
  <Tab title="Gemini CLI">
    Add the server, then sign in from Gemini CLI with `/mcp auth nitrosend`:

    ```bash
    gemini mcp add --scope user --transport http nitrosend https://api.nitrosend.com/mcp
    ```

    Full walkthrough in the [Gemini guide](/integrations/gemini).
  </Tab>
</Tabs>

Using **VS Code**, **Windsurf**, **Zed**, **v0**, or another client? See the [full integration guides](/integrations/overview).

### 3. Start prompting

Try this to get a full setup in one go:

```
Connect into Nitrosend and based on my brand, give me a suggested email
flow to set up and guide me through set up. Make the email design modern
and on brand against my website.
```

Your AI will scrape your brand, suggest a flow, build it, and walk you through sending a test.

<Tip>
  Other great first prompts:
  - "Check my account status and tell me what I need to set up"
  - "Create a 5-email welcome series for new subscribers"
  - "Send a test email to me@example.com"
</Tip>

## Quickstart with the dashboard

Prefer to set things up manually? Here's the traditional path.

### 1. Create your account

Sign up at [app.nitrosend.com](https://app.nitrosend.com) and complete the
onboarding wizard. Confirming your company identity reserves a protected
`hello@<brand-slug>.nitrosend.net` address derived from the Brand Kit company
name—not the account owner's name.

### 2. Activate a sender

In **Settings > Domains** ([app.nitrosend.com/my/settings/domains](https://app.nitrosend.com/my/settings/domains)), activate the protected Nitrosend address reserved for
your brand, or add the DNS records for a customer-owned sending subdomain.
Activation is an immediate local database operation under Nitrosend's already
verified shared sender root; it creates no per-brand DNS, DKIM, provider
identity, tenant resource, or background job. If a custom sender is already
selected, Nitrosend preserves it until you explicitly choose another sender.

### 3. Import contacts

Go to **Contacts > Import** ([app.nitrosend.com/my/contacts/import](https://app.nitrosend.com/my/contacts/import)) and upload a CSV, or add contacts manually. Each contact needs at least an email address.

### 4. Create a template

Head to **Templates** ([app.nitrosend.com/my/templates](https://app.nitrosend.com/my/templates)) and use the drag-and-drop editor to design your email. Your brand colors and logo are applied automatically.

### 5. Send a campaign

Go to **Campaigns > New** ([app.nitrosend.com/my/campaigns](https://app.nitrosend.com/my/campaigns)), select your template and audience, and hit send.

## Using the REST API

If you prefer to integrate programmatically, grab your API key from **Settings > API Keys** ([app.nitrosend.com/my/settings/api-keys](https://app.nitrosend.com/my/settings/api-keys)) and check the [API Reference](/api/).

```bash
curl -X POST https://api.nitrosend.com/v1/my/messages \
  -H "Authorization: Bearer nskey_live_..." \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: welcome-user-123" \
  -d '{
    "channel": "email",
    "to": "user@example.com",
    "subject": "Hello from Nitrosend",
    "html": "<h1>Welcome!</h1>",
    "body": "Welcome!"
}'
```

Live email requires one ready, selected sender. Materialize the reserved
Nitrosend brand-subdomain sender with
`POST /v1/my/brands/{sid}/prepare_sending`, or verify a domain you own. Send
`{"subdomain": "<name>"}` to choose the name; with no body the call derives it
from the company name and needs the complete Brand Kit. The
operation completes synchronously and selects the new sender only when the
brand has no existing selection. An eligible first API request can perform the
same local materialization before admission. If the shared root is unavailable,
the API returns retryable `hosted_sender_root_unavailable`, stores no message,
and the same idempotency key is safe to retry.
